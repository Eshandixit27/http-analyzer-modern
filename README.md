# HTTP Analyzer (Modern)

HTTP Analyzer is a simple Node.js project that helps analyze HTTP requests and responses for learning and debugging purposes.

## 📌 Features
- Analyze HTTP requests
- Inspect headers and payloads
- Simple Node.js server
- Beginner-friendly code structure

## 🛠 Tech Stack
- Node.js
- JavaScript
- HTTP module

## 📂 Project Structure
- `server.js` – Main server file
- `analyzer.js` – HTTP analysis logic
- `public/` – Static files

## ▶️ How to Run the Project

1. Install Node.js
2. Open terminal in project folder
3. Run:
```bash
npm install
node server.js
